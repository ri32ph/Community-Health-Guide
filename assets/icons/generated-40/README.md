## 共通の生成仕様

ホームページの温かな地域医療イラストを基準に、やさしい日本の絵本のような水彩・色鉛筆調、丸みのある手描き形状、紙の質感、アイボリー・緑・空色・青緑・ラベンダー・珊瑚色・黄色の配色で生成しました。各画像は一つの場面に絞り、人物や道具の全体を画像内に収め、文字・ロゴ・枠・背景パネル・透かしを入れない指定です。

生成後、全40点を1024×1024pxへ統一し、外周に透明な安全余白を追加しました。アルファ領域を検査し、画像端に触れている要素がないことを確認しています。
